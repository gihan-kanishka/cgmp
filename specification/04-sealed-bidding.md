# Driver Bidding - retired from the v1.4 reference design

Earlier CGMP drafts explored an exceptional sealed first-qualifying fallback after deterministic search failure.

CGMP v1.4 removes that mechanism from the reference framework.

If passenger-authorized deterministic search fails, the request may remain unmatched or enter an operational retry/rematch flow at the same published tariff. The reference design does not introduce a discretionary driver premium, passenger bidding ceiling, or platform-selected scarcity multiplier.

This file is retained only so historical links do not silently break.
